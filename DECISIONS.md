- **Timing model: audio-driven from day one.** Render service generates TTS per beat, measures durations, passes them as Remotion input props; underline draw and beat reveals sync to voice. Never fixed-frame timing.

## 1. Goal

Add short-form video (Instagram Reels + Facebook Reels) to the Sacred Cosmos pipeline. At the current stage (~1 follower), reels are the cold-discovery growth engine; carousels are the retention layer. Design system to be rebuilt once and shared across posts and reels.

## 2. Content strategy

- **Reels (2/day):** Manifestation reel in the morning, Elements reel in the evening (6+ hrs apart — Elements carries the community questions, so it closes the day's engagement).
- **Posts (carousels):** Daily sign carousels (2 parts), daily overview as carousel intro slide, weekly forecasts.
- **Weekly signs fix:** Graph API caps carousels at **10 children** (app-side 15–20 limit does not apply to API publishing). Weekly restructured to **1 slide per sign** → intro + 6 = 7 slides per part, 2 parts. Trimmed fields (Heart Guidance / Life Purpose / Spiritual Insight / Lucky Moments) move into the caption.
- **Not in v1:** weekly Sunday reel, overview reel (rotate in later based on data).
- **Format targets:** reels 12–15s, loop-friendly, under-15s save/share-optimized. Saves and shares are the reach currency; astrology content is natural save-bait ("save your sign") and share-bait ("send this to a Leo").

## 3. Audio

- Trending IG audio is **not available** via Graph API publishing — audio must be baked into the mp4.
- v1: royalty-free ambient track baked in at render.
- Later A/B: soft TTS voiceover (edge-tts, free) reading the hook/beats.

## 4. Video generation approach

- **Engine: Remotion** (React-based, free license for solo use). Chosen over FFmpeg (less design control) and cloud APIs like JSON2Video/Creatomate (~$50/mo recurring, over budget).
- **Budget:** ≤$20/mo. Actual plan: ~$10 **one-time** for AI background library, ~$0/mo recurring.
- **Backgrounds:** one-time batch of ~16 looping 9:16 cosmic clips via fal.ai budget models (Wan / Kling / Seedance tier), stored in Supabase Storage, selected deterministically by Cosmic Seed.
- **Local AI video ruled out:** Quadro T600 (4GB VRAM) can't run current video models; M4/16GB marginal.

## 5. Architecture

Human-in-the-loop via dashboard (matches existing publish pattern):

1. **Dashboard:** "🎬 Manifestation Reel" / "🎬 Elements Reel" buttons → POST `{composition, date}` via Netlify proxy (same CF Access pattern as `publish.mjs`) → n8n render webhook.
2. **Render service:** Docker container on the Proxmox homelab (Express + `@remotion/renderer`). Pulls day's payload from `cosmic_data`, renders 1080×1920, uploads mp4 to new public `social-videos` Supabase bucket, writes `reel_renders` row (`status`, `video_url`). CPU render is fine (~ a few minutes per 15s clip on the i5-11500).
3. **Dashboard preview:** poll or Supabase-realtime on `reel_renders` → inline `<video>` preview + auto caption.
4. **Publish:** existing publish flow, payload gains `post_type: 'reel'` + `video_url`.
5. **Publisher v2.2:** new Reels branch — IG container `media_type=REELS` → **poll `status_code` until FINISHED** (replaces fixed Wait; required for video) → publish. Parallel FB Reels branch. Also implements the weekly 7-slide restructure.

## 6. Content generation changes (Daily Workflow v8.5)

Current text is written for static images; reels need timed beats. Extend the Enhanced Daily Generator JSON schema (single source of truth, reviewed via existing Telegram flow, no extra API calls):

```
reel_scripts: {
  manifestation: { hook, beats[3-4], cta, caption },
  elements:      { hook, fire, earth, air, water, cta, caption }
}
```

Prompt-enforced budgets: hook ≤8 words, beats ≤14 words each → 12–15s total on-screen time. Parser updated accordingly.

## 7. Brand redesign

- **Scope:** full redesign, not adaptation — no follower base to protect, so pick the strongest system outright.
- Sign slides drop emoji titles entirely; zodiac **glyphs as typographic/design elements**.
- **Single source of truth:** `brand.tokens.json` (colors, gradients, type scale, spacing, glyph treatments) consumed by both dashboard `constants.js` and the Remotion theme.
- Gradient library shrinks from 16 to a disciplined family (4 element-tinted duotones + 2 neutrals on a shared dark base) — feed reads as one body of work.
- Design's job: signal the voice (direct, unmystical astrology) in the first half-second. The writing is the differentiator; design must not bury it in cosmic clichés.
- **Two candidate directions mocked (Step 0):**
  - **A — Observatory:** dark editorial almanac. Near-black indigo, celestial gold accent, Fraunces + Newsreader, constellation linework, film grain, glyph-as-star-chart. Motion: star drift, glyph parallax, slow type reveals.
  - **B — Field Notes:** ink on paper. Bone ground, Courier Prime mono, red-ink editor's marks, rubber-stamped glyph. Light card in a dark-purple niche. Motion: typewriter reveal, underline draw.
- **Pending:** pick A or B, then tokenize.
